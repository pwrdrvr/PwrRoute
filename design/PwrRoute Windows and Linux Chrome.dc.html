Pick 1a and 1b. They are PwrGit's shipped behaviour, so the family stays consistent per OS rather than across them. For the GPUI build: the strip's gutter becomes a platform switch, x=16 off macOS. On Windows the 150px reserve and a 40px caption height must be set when the window is made, and the overlay colours repaint on a theme change. On Linux the window is frameless, so PwrRoute draws its own edge and three buttons, and the maximize glyph follows the window's real state, not the last click. The Settings window takes the same rules, with its own crumb.
