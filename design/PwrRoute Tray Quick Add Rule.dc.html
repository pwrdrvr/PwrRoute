1Menu bar › + Rule on a recent link

The tray’s Recent rows are the links people most often want a rule for, right after one opened in the wrong place, and the only way from there to a rule was Open Activity, find the row, then + Rule. Now a recent row does what an Activity row does (Activity Quick Add Rule 1a): while the pointer is over it, its age gives way to + Rule. A click closes the dropdown and opens the main window on Activity with that row selected and the Add a rule sheet open for its link. The sheet is Activity’s, unchanged; only its eyebrow says where it came from.

1aThe pointer is over the second recent link. The row lights, 2m gives way to + Rule in the accent, and the tooltip names the action. Nothing moves: the button is 20 high, inside the row’s two lines, and right-aligned where the age was. Off the row, the age comes back.

2Menu bar › Add a rule for the next link

Some links are hard to write a rule for after the fact: they open, redirect and are gone, or the app that sent them never shows the URL. Hold already catches them (Incoming Links 2c), but the person then has to open the dropdown again, find the held link and choose Make a rule…. This is the one-shot version: arm it from the dropdown, click the link in any app, and PwrRoute does not open it; the main window comes forward with the Add a rule sheet for that link. The person picks the pattern and where it opens, then chooses Discard, Save or Save and open link, which saves the rule and opens the link where the new rule says.

2aThe item sits first among the actions, above Test a link…, since both take a link to the rules. It is an action, not a fifth answer in the Incoming links switch: it lasts one link and never has a For row, and the switch is full at 300px. It has no key; ⌘N already means “a rule for this row”.
