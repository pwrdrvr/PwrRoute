Two changes to Activity’s Add a rule sheet (Activity Privacy and Route Tests 2c). The link in the head is two lines at most: host and path in the primary text, the query after it in the secondary, cut with an ellipsis, and under it Show full link with the count of query parameters. An OAuth or tracking link used to push Match and the buttons off the sheet; now the head is the same height for every link. Show full link opens it in place, scrolling past eight lines. Any link from Linear is the first choice under Match whenever the record names the app that sent the link. It is the whole rule in one click: the pattern becomes *, Sent from turns on, and Also catches lists only the recent links that app sent. The sheet still picks the narrowest pattern first; the app is offered, never chosen for the person.

Why * and not a new kind of rule. A rules.json rule already has opener, and Finicky’s matcher reads * as every link, so “any link from Linear” is { "match": "*", "opener": ["com.linear"], "browser": … }: the Go host’s schema plus the existing extension, shown in Rules like any other rule. Its Also catches filters by the app as the router would, so the list says what the rule takes, not every link in memory. Position still decides: at the bottom an earlier rule that matches a Linear link keeps it, and the caption says so.
