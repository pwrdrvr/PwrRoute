Which rows. + Rule shows on a row whose record kept its full URL (the same rows whose expanded view offers Add a rule…), live or from the journal, routed or not, failed or not. A routed row gets it too: a narrower rule for one link of a busy rule is a common fix. Never on a host-only row, nor on the expanded row (its primary button is right below). Click. Opens the Add a rule sheet for that row without expanding or collapsing it. Keyboard. ⌘N (Ctrl+N) with the main window’s list focused: the row whose “⋯” menu is open, else the expanded row; nothing when neither. It does what the menu item it is shown on does, so a host-only row gets the sheet’s disabled state with the reason. Measurements. The button is 20 high and fits the 48px Took column: 10.5/600 label, 11/700 accent “+”, 4 gap, 7 side padding, radius 5. At rest (Everything else): transparent, --border-subtle, --text-secondary. Lit (hovered row): --accent-soft fill, --accent-border, --accent-bright. The tooltip is the app’s usual one with the key in a .kbd. The expanded row’s link is mono 11.5 on 16.5 lines, two at most.
