6First run: let PwrRoute see browser profiles (macOS)

From macOS 27, reading another app's files needs the user's say-so in Privacy & Security › Files & Folders. macOS does not ask: it posts “PwrRoute was blocked from accessing other apps' data” and leaves the switches off, so the Everything else select can name a browser but none of its profiles. When the scan finds a browser whose profile list exists but cannot be read, first run gains a step before everything else that says why PwrRoute needs it, opens the pane, and draws the switches the user will find there, with the apps' own icons. The step re-reads whenever the window comes back to the front and on Check again; Skip leaves the profiles out. Browsers that read fine are never named.

6aNo config, two browsers blocked. The access step comes first, so the window has three steps. The panel is a copy of what Files & Folders will show under PwrRoute: one row per blocked browser, its switch off, “Turn on” beside it.

When it shows. macOS only, and only when the scan found a browser whose profile file is there but cannot be read (permission denied). A browser with no profiles, or one never opened, is not blocked. The step goes first, before the config step when there is one (four steps then): it is what macOS's notice is about, and step 2's profile select needs it. Copy. The paragraph names the blocked browsers in the scan's order (“A”, “A and B”, “A, B and C”) and always says what is read and what is not. Open Files & Folders opens x-apple.systempreferences:com.apple.preference.security?Privacy_FilesAndFolders. Re-reading. On Check again and whenever the window becomes active again after losing focus (not on its first activation, which follows the scan it opened with), never on a timer: each blocked read can post macOS's notice again. A read re-reads profiles only (no icon reload). Measurements. The panel is the step body's width: radius 9, a 10.5 crumb row, 34px rows, kid rows indented 34, 18px app icons, the shared .sw. A row still to do is tinted --bg-row-active with an accent ring round its switch.
