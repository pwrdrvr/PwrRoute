1Rules › Add a handler

Add handler from the pane head. The real choice is where the new rule is edited: in the rail that already edits every rule, or in a sheet of its own. Either way a handler saves only once it has a pattern and a browser, because RulesFile::problems() refuses one without them (“Add at least one match pattern.”, “Select a browser.”), and a new handler lands at the end of the list, just above Everything else. Order is the meaning of a handler list, so Try it says when an earlier rule would win.

1aRecommended. A draft row 08 appears, selected, and the rail opens on it with the pattern field focused. The browser menu lists detected browsers with their profiles; an app that is not installed stays listed, dimmed. Nothing is written until the draft is complete.

2Rules › Add a rewrite · the rewrite editor

A rewrite is a match plus an ordered list of changes, the five RewriteActions rules.json can hold: set host, set scheme, replace path, drop query parameters, replace the whole URL. The rail edits one rewrite at a time. Try it shows the URL before and after, highlighting each part a change touched, the same marks Test a link uses, then names the handler that would take the result.

2aRewrite 1 selected. Two changes, applied top to bottom; each row is a kind and a value, and its grip reorders it. Every matching rewrite applies, so Try it also lists the other rewrites that would run.

3Rules › Reorder

Reordering handlers changes where links go, so the drag says how much before the drop. The router keeps the last hundred dispatches in memory; PwrRoute re-resolves them against the proposed order and counts the links whose browser would change. Rows move only within their own list: a handler cannot become a rewrite, and the other card dims while a row is lifted. Cropped to the pane.

3aHandler 3 lifted and held between 1 and 2. Its old place closes up and the list opens a gap where it will land. Dropping saves and reloads at once, and the change is one ⌘Z away.

4Rules › Delete with undo

Delete is immediate: no confirmation, the file is saved and the router reloads. Undo restores the rule at its old index with its hit count. The choice is where Undo lives. ⌘Z works in both and stays good until the next edit or until the window closes.

5Rules › Validation errors

A rule with a problem is not saved; the router keeps routing with the last saved version of that rule, and every other edit still saves. Messages are RulesFile::problems()'s own words, shown under the field they belong to. Problems block saving; warnings, such as a pattern that matched none of the recent links, never do.

5aHandler 4 being edited. A regex that does not compile and a browser that would send the link straight back. The row keeps showing the saved version with a not-saved badge. Cropped to the pane and rail.
