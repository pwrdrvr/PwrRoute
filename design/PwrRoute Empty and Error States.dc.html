2Error states

Three failures, each with a different fallback. A config that fails to load leaves the last good version routing, so the error is news, not an outage. A matcher that times out hits the 1 s resolve budget (Limits::resolve); a matcher that throws still gets the config's default browser, as in Finicky, but a deadline stops the whole resolve, so the router opens its own fallback: Safari on macOS, Edge on Windows, Firefox on Linux. A browser that is not installed cannot open the link, so the fallback opens it and the trace says why. Nothing is ever dropped.

2aA save of ~/.finicky.ts that does not parse. The banner turns danger, with oxc's message and a code frame. Below it the read-only lists are the version still routing, labelled with its load time.
